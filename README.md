# Creative Prompt Testing Studio

## Project Overview
Creative Prompt Testing Studio is a beginner-friendly Python project that helps compare different prompts for the same creative task.

The project tests three prompts that generate startup ideas for college students.

## Objectives
- Understand how prompt wording affects AI responses.
- Compare simple, detailed, and example-based prompts.
- Evaluate AI responses using a scoring system.
- Save experiment results in a Markdown file.

## Technologies Used
- Python
- Visual Studio Code
- ChatGPT
- Markdown

## Project Files
- `prompt_studio.py` — Runs the prompt testing program.
- `experiment_results.md` — Stores AI responses, evaluation scores, and observations.
- `README.md` — Describes the project.

## How to Run
1. Install Python.
2. Open the project folder in Visual Studio Code.
3. Open the integrated terminal.
4. Run:

   `py prompt_studio.py`

5. Choose an option from the menu.
6. Select a prompt and record the actual AI response.
7. Enter scores from 1 to 5 for creativity, relevance, tone, and level of detail.

## Evaluation Criteria
Each response is evaluated on four criteria:
- Creativity
- Relevance
- Tone
- Level of detail

Each criterion is scored out of 5, giving a maximum total of 20.

## Learning Outcomes
- Writing clear and specific prompts.
- Comparing AI-generated responses.
- Evaluating outputs using consistent criteria.
- Saving experiment results using Python.

## Important Note
The AI responses and scores in `experiment_results.md` should be the actual results collected during testing. Observations should describe the differences noticed in the experiments.
